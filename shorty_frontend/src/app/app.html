Shorty
Angular ASP.NET Core PostgreSQL
Live – bereit für deine Links

Mache lange Links kurz.

Füge eine URL ein, wähle optional wie lange der Link gültig sein soll und teile im Handumdrehen einen knackigen Short-Link.

  • Persistent gespeichert

    Jeder Link lebt sicher in einer PostgreSQL-Datenbank.

  • Flexibles TTL

    Von einer Stunde bis zu 30 Tagen frei wählbar.

  • Blitzschnell

    Die Kurz-URL ist sofort bereit zum Teilen.
